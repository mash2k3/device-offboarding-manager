Playbooks

Personal and Stale now use tenant-specific heuristics (confirmed against this tenant's actual data, not official Microsoft fields): Personal = any device with an Entra record but no matching Intune-managed record. Stale = no Intune sync or Entra sign-in in the last 6 months, built from the same merged Intune+Entra universe as OS-Specific. Corporate and OS-Specific are unchanged (Intune's managedDeviceOwnerType and operatingSystem fields work correctly via server-side $filter).
